🌐 Buka Supabase & Paste SQL

Klik tombol di bawah untuk membuka Supabase SQL Editor:

⚠️ Setelah Supabase terbuka:
  1. Pastikan Anda sudah login
  2. Klik di area editor (kotak putih besar)
  3. Tekan Ctrl + V untuk paste SQL
  4. Klik tombol "RUN" di pojok kanan bawah
  5. Tunggu sampai muncul pesan "Success"
