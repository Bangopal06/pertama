🔧 Fix Storage RLS - Copy SQL Ini

SQL untuk disable RLS di Storage:

-- Disable RLS untuk bucket siswa-documents
ALTER TABLE storage.objects DISABLE ROW LEVEL SECURITY;

-- Atau buat policy yang allow semua
CREATE POLICY "Allow all operations on siswa-documents" 
ON storage.objects 
FOR ALL 
USING (bucket_id = 'siswa-documents');

-- Set bucket sebagai public
UPDATE storage.buckets 
SET public = true 
WHERE id = 'siswa-documents';

  1. Klik tombol "Copy SQL" di atas
  2. Buka Supabase SQL Editor
  3. Paste dan Run SQL
