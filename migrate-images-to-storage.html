Tool untuk memindahkan gambar dari database (base64) ke Supabase Storage

⚠️ Peringatan:
- Proses ini akan mengubah URL gambar di database
- Pastikan bucket sudah dibuat (jalankan setup-storage-images.sql)
- Backup database sebelum menjalankan migrasi
- Proses tidak bisa di-undo
ℹ️ Cara Kerja:
1. Scan semua berita dan program yang punya gambar base64
2. Convert base64 ke file
3. Upload file ke Supabase Storage
4. Update URL di database
5. Gambar base64 otomatis terhapus dari database
